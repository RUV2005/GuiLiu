# 归流 GUILIU

[简体中文](README.md) | **日本語** | [English](README.en.md)

**家計の記録を自動で整理し、変化の理由を説明し、目標まであとどれくらいかを伝え続けます。**

归流（GUILIU）は、自分のパソコン上で動く AI 家計管理ワークスペースです。銀行の利用通知メール、レシートの画像、Alipay・WeChat Pay の明細から支出を自動で集め、信頼できる家計簿にまとめます。レポート形式のホーム画面と分析する Agent が、お金の使い道、先月との違い、貯蓄目標までの残りをわかりやすく示します。

日々の入力・分類・重複チェックは归流に任せ、確認が必要な少数の例外だけを処理すれば十分です。

## 機能

- **明細の自動取り込み**：Gmail または NetEase 163 メール（同時接続可）の銀行利用通知を読み取り、ルールと大規模言語モデルで店舗名・金額・通貨・日時を抽出し、分類と重複チェックを経て記帳します。認識ルールは送信元ごとに自動生成され、内蔵の銀行リストには依存しません。
- **レシート・明細の取り込み**：メールで送ったレシートや支払い画面のスクリーンショットを認識して記帳します。Alipay・WeChat Pay の明細（CSV / Excel）の取り込みにも対応し、プレビューで確認・修正でき、重複の疑いがあるものは確認してから書き込みます。
- **明細の補完（ADR）**：銀行の引き落とし 1 件ごとにメールやレシートから根拠を探し、商品明細を元の取引の下に追加します。支出が二重に計上されることはありません。
- **レポート形式の概要**：ひと言サマリー、今月と先月の日別比較、カテゴリ別の要因、年間カレンダーのヒートマップ。日付・口座・主要通貨（日本円 / 人民元）で切り替えられます。
- **資産と口座**：銀行・現金・クレジット口座と、複数通貨を換算した純資産・残高の推移。
- **分析する Agent**：自然な言葉で質問すると、結論・主要な数字・関連する取引・グラフ付きレポートが返ってきます。連続した会話、Web 検索、好みのプロフィールに対応します。
- **目標・自動タスク・Agent からの提案**：貯蓄 / 投資プランと進捗、定期実行の自動タスク、Agent が見つけた気づきや確認事項。
- 中国語・日本語・英語の 3 言語 UI、ライト / ダークテーマ。

## データは手元に

- 3 つのサービスはローカルアドレスでのみ待ち受け、家計簿・ベクトルデータベース・会話履歴・認証情報・ログはすべてプログラムフォルダ内の `.runtime/` に保存されます。ブラウザからアクセスするにはこのパソコンとのペアリングが必要で、ペアリングはランチャーが自動で行います。
- Windows 版は設定の「バージョンと更新」からワンクリックで更新できます。更新パッケージは署名を確認し、切り替え前にデータを自動でバックアップし、新しいバージョンが起動しない場合は元のバージョンに自動で戻ります。
- メールは読み取るだけで、送信・削除・既読化は行いません。Gmail は Google 認証（読み取り専用）またはアプリ パスワード（SSL IMAP）で、163 メールは IMAP 認証コードで接続します。
- 外部サービスを使う処理：メールの読み取り（Google / NetEase）、情報の抽出と対話（通義千問 / Qwen）、テキストのベクトル化（OpenAI）、Agent の Web 検索、為替レートと相場（ExchangeRate-API、Frankfurter、Yahoo Finance、gold-api.com）。関係するメールやレシートの内容は自分で設定したモデルサービスに送信され、利用料金は各サービス事業者から請求されます。
- 归流は 1 台のパソコンで 1 人が使うためのものです。サービスを LAN やインターネットに公開しないでください。

## ダウンロードと使い方

**[最新版をダウンロード](https://github.com/rhinoqvq/GuiLiu/releases/latest)**（Windows 10 / 11、64 ビット）

1. 上のページから `GUILIU-<バージョン>-win-x64.zip` をダウンロードします。ポータブル版には Python 3.13、Node 22 とすべての依存パッケージが含まれており、ほかに何もインストールする必要はありません。
2. 書き込み権限のあるフォルダ（デスクトップなど）にすべて展開し、`start_windows.cmd` をダブルクリックします。ランチャーが空いているポートを自動で選び、ブラウザを開きます。
3. 初回は画面の案内に従って初期設定を行います：API の設定と接続テスト → Gmail / 163 の接続 → メールのインデックス作成 → 銀行の送信元の識別 → 口座の確認 → レシートを送るメールアドレスの設定 → 完了。

必要なもの：Windows 10 / 11（64 ビット）、通義千問（Alibaba Cloud Model Studio）の API キー、OpenAI の API キー、Gmail または 163 のメールアカウント。展開したパッケージ内の `README.md` が使い方、`DEPLOYMENT.md` がデプロイと運用の詳細です（いずれも中国語）。

メールの自動同期・明細の補完・自動タスクは既定でオンになっており、初期設定が終わってから動き始めます。メールの自動同期は設定画面でオフにできます。

## リポジトリ構成

| ディレクトリ | 内容 |
| --- | --- |
| `frontend/` | 素の HTML / CSS / JavaScript による UI と Node.js のローカルサーバー（静的ファイル、ローカルペアリング、同一オリジンのプロキシ）。ビルド手順はなく、`npm install` も不要 |
| `backend/` | Python / FastAPI：メールの読み取り（Gmail API、IMAP）、日次処理ループ、ルール抽出、明細の取り込み、家計簿と資産の計算、初期設定フロー。保存先は SQLite |
| `agent/` | Python / FastAPI：LLM の呼び出し（Qwen）、埋め込み（OpenAI）と LanceDB ベクトルデータベース、ツール実行、レシート認識、分類、明細の補完、プランと自動タスク |
| ルート | 統合ランチャー `run.py`（3 つのサービスの一括起動、空きポートの自動選択、ブラウザのペアリング、一括停止）、スモークテスト `smoke.py`、依存関係リスト `requirements.txt` と `constraints.txt`、デプロイ説明 `DEPLOYMENT.md` |
| `release/` | ポータブル版のビルドスクリプト `build.py`・`portable.py`、ランタイム一覧 `RUNTIMES.json`、パッケージ同梱の説明 `README.package.md`。`release/windows/` は Windows 用の起動 / 停止 / インストールスクリプトで、ビルド時にパッケージのルートに配置されます |

3 つのサービスはそれぞれの認証情報で互いに認証し、ブラウザが長期的な鍵を受け取ることはありません。

## ソースから実行

Python 3.13 と Node.js 22 以上が必要です。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py serve
```

ランチャーがフロントエンド・バックエンド・Agent を一括で起動し、空いているポートを自動で選び（既定は 3000 / 8001 / 8000、使用中なら次のポートへ）、ブラウザを開いてペアリングします。実行データは `.runtime/` に書き込まれるので、Git にはコミットしないでください。デバッグ時は `--frontend-port`、`--backend-port`、`--agent-port` でポートを固定できます。Google 認証で「ウェブ アプリケーション」タイプのクライアントを使う場合は、バックエンドのポートを Google Cloud コンソールに登録したリダイレクト URI と一致させる必要があります。

0.1 のリリース候補版です。記帳、検索、資産、Agent による分析といった主要な機能は使える状態です。
