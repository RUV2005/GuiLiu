# Category Icons

Lucide SVG icons, version 0.468.0.
Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
License: ISC (see LICENSE).

All downloaded icons are unmodified. `utilities.svg` combines the same licensed
`droplet` and `zap` paths using SVG group transforms.

Served locally and tinted with CSS masks. The 38 existing category pairs have
explicit defaults in `src/category-icons.js`. Related pairs share a muted main
category color. Unlisted pairs use subcategory/main-category keyword fallback.
User-selected transaction and category overrides still take precedence.
